# Jonathan Lyngdoh — Portfolio

A personal portfolio built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Customize

- Update the copy and links in `index.html`.
- Replace `profile.jpg` to use a different portrait.
- Adjust the design tokens and responsive styles in `styles.css`.
- Scroll reveals, portrait parallax, orbit details, and the reading progress bar are built in plain JavaScript and CSS.
- Motion is reduced or removed when the visitor requests reduced motion.

## Deploy

Publish the repository root from the `main` branch in the repository's GitHub Pages settings.
